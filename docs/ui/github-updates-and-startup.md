# Windows 启动、托盘和应用更新

## 启动和后台运行

设置中的“登录时启动”控制当前 Windows 用户的 Run 启动项。Windows 仍可在系统启动设置中禁用该项。如果启动项指向另一份程序，设置页会显示原路径，并提供更新路径的操作。

“关闭窗口后在后台运行”默认开启，保存后生效。关闭主窗口时，程序保留同步和更新服务；单击托盘图标恢复窗口，右键选择“退出 GSYNC”结束进程。托盘图标不可用时，关闭窗口会退出程序，避免进程无法访问。再次启动同一数据目录的 GSYNC 会打开已有窗口。

## 应用更新

程序启动后及运行期间检查 GitHub 最新正式版，最多每天联网检查一次；手动检查不受此限制。GitHub API 限流时，程序使用发行页重定向及签名清单检查版本。自动检查与自动安装默认开启，可在设置中关闭。应用仅自动安装带可信签名的 Windows x64 发行包。

客户端使用内置 P-256 公钥验证发行清单，并核对版本、包名、文件大小和 SHA-256。发布工作流使用 `GSYNC_SIGNING_KEY_PKCS8_BASE64` Actions secret 签名；密钥缺失或与公钥不匹配时停止发布。

安装前等待同步队列及正在执行的比较、同步和恢复操作完成，并阻止新任务。独立更新器等待主进程退出，备份受管文件并替换，随后用隔离的数据副本检查新版本启动。检查失败时恢复旧文件；更新中断后，下次启动或登录会执行恢复。同一版本回滚后不会自动反复安装。

安装目录和数据目录不能重叠。旧版本如果没有更新器和 `GSYNC.managed.json`，需要先手动解压新版本。备份和恢复记录位于数据目录的 `updates` 文件夹；签名密钥轮换尚未实现。
